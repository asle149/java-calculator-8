# java-calculator-precourse

## 구현할 기능 목록

- [x] 기본 구분자(`,` `:`) 분리, 빈 문자열 입력 시 0을 반환
- [x] 커스텀 구분자 인식
- [x] 잘못된 입력 시 `IllegalArgumentException`을 발생시키고 종료
    - *커스텀 구분자 형식 오류*
        - 입력이 `//`로 시작하지만 `\n`이 없음
        - `//`와 `\n` 사이의 구분자 문자열이 비어 있음
    - *토큰화/값 검증*
        - 빈 토큰(연속 구분자)
        - 숫자가 아님
        - 0, 음수(양수만 허용)
- [ ] 계산기 구현
- [ ] 합산 결과 출력
